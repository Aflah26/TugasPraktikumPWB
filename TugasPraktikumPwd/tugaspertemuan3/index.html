ARTICLE - Pengenalan Layout Web

Layout web adalah struktur dasar dari tata letak elemen-elemen di halaman web. Penggunaan struktur semantic HTML seperti header, nav, article, aside, dan footer sangat membantu memperjelas struktur dokumen.

Dengan menggabungkan Flexbox dan CSS Grid, kita dapat merancang tampilan antarmuka web yang rapi, responsif, dan mudah diatur.
