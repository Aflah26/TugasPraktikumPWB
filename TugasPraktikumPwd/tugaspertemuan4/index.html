Belajar Membuat Website

Contoh halaman web sederhana untuk latihan tombol Back to Top menggunakan HTML, CSS, dan JavaScript.

Jelajahi Halaman

Tentang Website

Website ini dibuat sebagai contoh latihan pemrograman web. Halaman memiliki beberapa bagian agar pengunjung dapat melakukan scroll ke bawah.

Ketika halaman digulir lebih dari 500 piksel, tombol panah ke atas akan muncul di bagian kanan bawah layar. Tombol tersebut dapat digunakan untuk kembali ke bagian paling atas halaman.

HTML

HTML digunakan untuk membuat struktur dan isi halaman website.

CSS

CSS digunakan untuk mengatur warna, tata letak, jarak, dan tampilan halaman.

JavaScript

JavaScript digunakan untuk membuat tombol Back to Top menjadi interaktif.

Materi Pembelajaran

Berikut beberapa materi dasar yang dapat dipelajari ketika membuat website.

01

Struktur HTML

Mengenal elemen dasar seperti header, nav, main, section, dan footer.

02

Desain CSS

Mengatur tampilan website agar lebih rapi, menarik, dan mudah dibaca.

03

Interaksi JavaScript

Menggunakan event scroll, click, mouseenter, dan mouseleave.

04

Pengujian Website

Menguji halaman dengan melakukan scroll ke bawah dan mencoba tombol panah.

Informasi Tambahan

Silakan scroll halaman ini beberapa kali. Tombol panah akan tampil setelah posisi scroll melewati 500 piksel.

Secara bawaan, tombol memiliki opacity 50% agar tidak terlalu mengganggu isi halaman. Ketika pointer diarahkan ke tombol, opacity berubah menjadi 100% sehingga tombol terlihat lebih jelas.

Ketika tombol diklik, JavaScript menjalankan fungsi scroll ke posisi paling atas dengan efek gerakan yang halus atau smooth scrolling.
